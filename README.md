# NOVA League Platform

A React + Vite project built with TypeScript.

## Tech Stack

- **React + Vite**
- **TypeScript**
- **CSS**
- **ESLint**
- **Prettier**

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd NOVA League Platform

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```
